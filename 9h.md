Web Page to Hide Paragraph Using jQuery


index.html



<!DOCTYPE html>
<html>
<head>
    <title>Hide Paragraph using jQuery</title>

    <!-- jQuery Library -->
    <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

    <style>
        body {
            font-family: Arial;
            margin: 40px;
        }

        p {
            color: blue;
            font-size: 18px;
        }

        button {
            padding: 8px 15px;
            font-size: 16px;
        }
    </style>

    <script>
        $(document).ready(function() {

            $("#hideBtn").click(function() {

                $("#para").hide();

            });

        });
    </script>

</head>

<body>

    <h2>Hide Paragraph using jQuery</h2>

    <p id="para">
        Welcome to jQuery.

        jQuery is a lightweight JavaScript library that simplifies
        HTML document traversal, event handling, animations, and
        AJAX interactions.

        It follows the principle "Write Less, Do More."

        The jQuery library is loaded using the
        script tag.

        $(document).ready() waits until the webpage is fully loaded.

        $("#hideBtn").click() detects when the button is clicked.

        $("#para").hide() hides the paragraph with the ID para.

        <br><br>

        Click the button below to hide this paragraph.
    </p>

    <button id="hideBtn">Hide Paragraph</button>

</body>
</html>
