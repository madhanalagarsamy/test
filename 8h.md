Web Page in PHP to Fetch Details from MySQL Database



fetch.php

<!DOCTYPE html>
<html>

<head>
    <title>Fetch Records from MySQL</title>

    <style>
        table {
            border-collapse: collapse;
            width: 60%;
            margin: auto;
        }

        th, td {
            border: 1px solid black;
            padding: 10px;
            text-align: center;
        }

        th {
            background-color: green;
            color: white;
        }

        h2 {
            text-align: center;
        }
    </style>
</head>

<body>

    <h2>Student Details</h2>

    <?php

    // Connect to MySQL/MariaDB on port 3307
    $conn = mysqli_connect(
        "127.0.0.1",
        "root",
        "",
        "studentdb",
        3307
    );

    // Check connection
    if (!$conn) {
        die("Connection Failed: " . mysqli_connect_error());
    }

    // SQL query
    $sql = "SELECT * FROM student";

    // Execute query
    $result = mysqli_query($conn, $sql);

    // Check query
    if (!$result) {
        die("Query Failed: " . mysqli_error($conn));
    }

    // Display table
    echo "<table>";

    echo "<tr>";
    echo "<th>ID</th>";
    echo "<th>Name</th>";
    echo "<th>Department</th>";
    echo "<th>Email</th>";
    echo "</tr>";

    // Fetch records
    while ($row = mysqli_fetch_assoc($result)) {

        echo "<tr>";

        echo "<td>" . htmlspecialchars($row["ID"]) . "</td>";

        echo "<td>" . htmlspecialchars($row["Name"]) . "</td>";

        echo "<td>" . htmlspecialchars($row["Department"]) . "</td>";

        echo "<td>" . htmlspecialchars($row["Email"]) . "</td>";

        echo "</tr>";
    }

    echo "</table>";

    // Close connection
    mysqli_close($conn);

    ?>

</body>
</html>

## How to Run PHP + MySQL `fetch.php`

### 1. Install XAMPP

Install **XAMPP** with:

- Apache
- MySQL

---

### 2. Start XAMPP

Open **XAMPP Control Panel**.

Start:

```text
Apache
MySQL
```

Both should show as **Running**.

---

### 3. Create Project Folder

Go to:

```text
C:\xampp\htdocs
```

Create a folder:

```text
PHP-MySQL-Fetch
```

Put your PHP file inside:

```text
C:\xampp\htdocs\PHP-MySQL-Fetch\fetch.php
```

Folder structure:

```text
C:\xampp\htdocs\
│
└── PHP-MySQL-Fetch\
    │
    └── fetch.php
```

---

### 4. Create Database

Open your browser and go to:

```text
http://localhost/phpmyadmin
```

Click **New**.

Create database:

```text
studentdb
```

---

### 5. Create Student Table

Select `studentdb`.

Go to **SQL** and run:

```sql
CREATE TABLE student (
    ID INT AUTO_INCREMENT PRIMARY KEY,
    Name VARCHAR(100),
    Department VARCHAR(100),
    Email VARCHAR(100)
);
```

---

### 6. Insert Sample Data

Run:

```sql
INSERT INTO student (Name, Department, Email)
VALUES
('Jasmine', 'Computer Science', 'jasmine@gmail.com'),
('Ravi', 'Information Technology', 'ravi@gmail.com'),
('Priya', 'Computer Applications', 'priya@gmail.com');
```

Your database will look like:

```text
studentdb
    └── student
        ├── ID
        ├── Name
        ├── Department
        └── Email
```

---

### 7. Check MySQL Port

Your PHP code currently uses:

```php
3307
```

```php
$conn = mysqli_connect(
    "127.0.0.1",
    "root",
    "",
    "studentdb",
    3307
);
```

If your XAMPP MySQL is running on the **default port 3306**, change it to:

```php
$conn = mysqli_connect(
    "127.0.0.1",
    "root",
    "",
    "studentdb",
    3306
);
```

If your MySQL is actually configured for **3307**, keep `3307`.

---

### 8. Run the PHP Program

Open your browser and enter:

```text
http://localhost/PHP-MySQL-Fetch/fetch.php
```

You should see:

```text
             Student Details

+----+---------+----------------------+-------------------+
| ID | Name    | Department           | Email             |
+----+---------+----------------------+-------------------+
| 1  | Jasmine | Computer Science     | jasmine@gmail.com |
| 2  | Ravi    | Information Technology| ravi@gmail.com   |
| 3  | Priya   | Computer Applications| priya@gmail.com   |
+----+---------+----------------------+-------------------+
```

### Important

Don't open the PHP file directly like:

```text
C:\xampp\htdocs\PHP-MySQL-Fetch\fetch.php
```

PHP needs to be executed through Apache. Always use:

```text
http://localhost/PHP-MySQL-Fetch/fetch.php
```
